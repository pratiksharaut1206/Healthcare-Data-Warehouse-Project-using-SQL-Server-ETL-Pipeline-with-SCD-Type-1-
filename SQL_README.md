# HealthConnect Data Warehouse Project

## Overview
This project implements a healthcare data warehouse using SQL Server.

## Architecture
CSV → RAW → CLEANSED → REFINED → Reporting

## Features
- ETL Pipeline
- Data Cleaning (TRIM, UPPER)
- SCD Type 1
- Stored Procedures
- Master Procedure
- Reporting Views

## How to Run
Execute:
EXEC Proc_HealthConnect_Master_Load;

## Tools
SQL Server, SSMS
